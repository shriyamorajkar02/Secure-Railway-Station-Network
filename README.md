Secure Railway Station Network

Project Overview

A railway station network designed and simulated using Cisco Packet Tracer. The project demonstrates network segmentation, routing, server configuration, and secure remote device management.

Technologies Used

- Cisco Packet Tracer
- VLANs and Inter-VLAN Routing
- OSPF (Dynamic Routing)
- NAT (Network Address Translation)
- SSH and Telnet Restriction
- DNS and HTTP/HTTPS

Network Design

The network consists of routers, a core switch, departmental computers, and a server.


VLAN 10 - Ticketing
VLAN 20 - Administration
VLAN 30 - Management

Key Features

- VLAN-based departmental network segmentation.
- OSPF configuration for dynamic routing.
- NAT configuration at the network edge.
- SSH for secure remote management and Telnet restriction.
- Server configured with IP address "192.168.40.10" and DNS name "station.local".

Project Files

- "Secure_Railway_Station_Network.pkt" — Cisco Packet Tracer project file.

Learning Outcomes

Gained practical experience in network design, routing, VLAN configuration, server setup, and network security fundamentals.
